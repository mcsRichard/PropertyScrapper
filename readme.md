微信小程序
业务功能需求
功能	                描述
房产数据采集（爬虫Scrupper.py）	定期从国外房产网站(例如zoopla)抓取房源数据
图片存储	            下载房产图片并存放到云端
数据存储	            房源信息（城市、价格、面积、图片链接等）写入数据库
小程序展示浏览	        国内用户通过筛选浏览房产数据
快速 MVP 上线	        开发周期短、成本低、架构简单
内地访问无障碍	        小程序后端必须可被国内用户顺畅访问

架构图

国外房产网站数据  →  爬虫脚本（部署境外Serverless）
                        ↓
               上传房源图片到 COS
                        ↓
           数据写入数据库（TDSQL-C Serverless）
                        ↓
          SCF 云函数提供 REST API（HTTP）
                        ↓
                已备案域名 + SSL
                        ↓
                微信小程序前端
                国内用户快速访问

各部分组件说明

模块	技术选择	说明	部署位置
微信小程序	原生小程序/UniApp	用户端界面、筛选浏览房源	微信端
后端 API	腾讯云 云函数 SCF（HTTP 函数 URL）	替代 API 网关，响应小程序请求	国内
数据库	TDSQL-C Serverless（或 MySQL Serverless）	房产数据结构化存储	国内
图片存储	腾讯云 COS 对象存储	小程序图片展示来源	国内
域名与访问	已备案域名 + DNS + 免费 SSL证书	小程序合法服务器域名要求	腾讯云
爬虫服务	✅ 部署在海外 Serverless（如海外 SCF）	避免国外网站封锁国内 IP	国外
