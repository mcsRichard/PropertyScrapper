# 房产多张图片展示实现流程

## 概述

系统支持每套房产显示多张图片，从数据库存储到前端展示的完整流程。

## 1. 数据库层

### 1.1 数据模型

**表名**: `property_images`

**模型**: `PropertyImage` (定义在 `backend/models/database.py`)

```python
class PropertyImage(Base):
    """房产图片模型"""
    __tablename__ = "property_images"
    
    id = Column(Integer, primary_key=True, index=True)
    property_id = Column(Integer, ForeignKey('properties.id'))  # 关联房产ID
    
    # 图片URL相关
    source_url = Column(String(500))      # 原始来源URL（如Zoopla图片地址）
    image_url = Column(String(500))      # COS访问URL（对外可访问）
    cos_key = Column(String(500))        # COS对象键（用于幂等与定位对象）
    image_path = Column(String(500))    # 可选：本地临时保存路径
    
    # 排序和标记
    order_index = Column(Integer, default=0, index=True)  # 图片顺序（从0或1开始）
    is_primary = Column(Boolean, default=False, index=True)  # 主图标记
    
    # 图片尺寸
    width = Column(Integer)
    height = Column(Integer)
    
    created_at = Column(DateTime, default=datetime.utcnow)
```

**关键字段说明**:
- `property_id`: 关联到具体的房产
- `order_index`: 图片显示顺序（数字越小越靠前）
- `is_primary`: 是否为主图（主图会优先显示）
- `image_url`: COS存储的图片URL，用于前端显示

**数据库约束**:
- `UniqueConstraint('property_id', 'order_index')`: 同一房产下的顺序唯一
- `UniqueConstraint('cos_key')`: 同一COS对象键全局唯一

### 1.2 数据关系

```
properties (房产表)
    ↓ (一对多)
property_images (图片表)
```

一个房产可以有多张图片，通过 `property_id` 外键关联。

## 2. 后端API层

### 2.1 数据查询

**方法**: `PropertyService.get_images_by_property_id()` 
**位置**: `backend/utils/database.py`

```python
def get_images_by_property_id(self, property_id: int) -> List[PropertyImage]:
    """获取房产所有图片，主图优先，其次按顺序"""
    return (
        self.db.query(PropertyImage)
        .filter(PropertyImage.property_id == property_id)
        .order_by(
            desc(PropertyImage.is_primary),  # 主图优先
            asc(PropertyImage.order_index),  # 然后按顺序
            asc(PropertyImage.id)             # 最后按ID
        )
        .all()
    )
```

**排序逻辑**:
1. 主图 (`is_primary=True`) 优先显示
2. 然后按 `order_index` 升序排列
3. 最后按 `id` 升序排列（保证稳定性）

### 2.2 API端点

**端点**: `GET /api/properties/<property_id>`
**位置**: `backend/api/properties.py`

```python
@properties_bp.route('/<int:property_id>', methods=['GET'])
def get_property_detail(property_id: int):
    """获取房产详情"""
    # ... 获取房产基本信息 ...
    
    # 追加图片列表
    images = property_service.get_images_by_property_id(property_id)
    property_data['images'] = [{
        'id': img.id,
        'source_url': img.source_url,
        'image_url': img.image_url,        # 主要使用这个字段
        'cos_key': img.cos_key,
        'order_index': img.order_index,
        'is_primary': img.is_primary,
        'width': img.width,
        'height': img.height,
        'created_at': img.created_at.isoformat() if img.created_at else None
    } for img in images]
    
    return jsonify({
        'success': True,
        'data': property_data
    })
```

### 3.2 数据处理

**文件**: `miniprogram/pages/detail/detail.js`

```javascript
loadPropertyDetail(id) {
  api.getPropertyDetail(id)
    .then(res => {
      if (res.success && res.data) {
        const property = res.data
        
        // 规范化图片数组：优先使用后端 images，否则退化为单图 image_url
        let imageUrls = []
        if (Array.isArray(property.images) && property.images.length > 0) {
          imageUrls = property.images
            .filter(img => {
              // 过滤掉没有URL的图片
              return !!(img.image_url || img.url)
            })
            .sort((a, b) => {
              // 主图优先，然后按order_index排序
              const aPrimary = a.is_primary ? 1 : 0
              const bPrimary = b.is_primary ? 1 : 0
              if (aPrimary !== bPrimary) {
                return bPrimary - aPrimary
              }
              return (a.order_index || 0) - (b.order_index || 0)
            })
            .map(img => {
              // 优先使用image_url，其次url，最后source_url
              return img.image_url || img.url || img.source_url
            })
            .filter(url => {
              // 过滤无效URL（必须是http开头）
              return url && typeof url === 'string' && url.trim().startsWith('http')
            })
        } else if (property.image_url) {
          // 如果没有images数组，使用单图
          imageUrls = [property.image_url]
        }
        
        // 前端去重
        const seen = new Set()
        imageUrls = imageUrls.filter(url => {
          if (seen.has(url)) {
            return false
          }
          seen.add(url)
          return true
        })
        
        // 设置到页面数据
        this.setData({
          property: {
            ...property,
            imageUrls: imageUrls  // 处理后的图片URL数组
          },
          currentImageIndex: 0
        })
      }
    })
}
```

**处理流程**:
1. 检查是否有 `images` 数组
2. 过滤掉没有URL的图片对象
3. 排序：主图优先，然后按 `order_index`
4. 提取URL：优先 `image_url`，其次 `url`，最后 `source_url`
5. 过滤无效URL（必须是http开头）
6. 前端去重（移除重复URL）

### 3.3 UI展示

**文件**: `miniprogram/pages/detail/detail.wxml`

```xml
<!-- 图片轮播 -->
<view class="detail-swiper-wrapper" wx:if="{{property.imageUrls && property.imageUrls.length > 0}}">

    class="detail-swiper"

    indicator-color="rgba(255,255,255,0.5)"

    bindchange="onSwiperChange">        <!-- 切换事件 -->

      <swiper-item class="swiper-item">
        <image 
          class="detail-image" 
          src="{{imgUrl}}" 
          mode="aspectFill"              <!-- 保持纵横比填充 -->

          lazy-load="{{false}}" />
      </swiper-item>
    </block>

  <!-- 图片计数器：显示 1/5 -->
  <view class="image-counter" wx:if="{{property.imageUrls && property.imageUrls.length > 1}}">
    <text>{{currentImageIndex + 1}} / {{property.imageUrls.length}}</text>
  </view>

<!-- 如果没有图片，显示占位图 -->
<view class="detail-swiper-wrapper" wx:if="{{!property.imageUrls || property.imageUrls.length === 0}}">
  <view class="detail-image-placeholder">
    <text class="placeholder-text">暂无图片</text>
  </view>
</view>
```

### 3.4 交互功能

**图片预览**: 点击图片可全屏预览所有图片

```javascript
previewImage(e) {
  const index = e.currentTarget.dataset.index || 0
  const urls = this.data.property?.imageUrls || []
  if (!urls.length) return
  
  wx.previewImage({
    current: urls[index],    // 当前显示的图片
    urls                      // 所有图片URL数组
  })
}
```

**Swiper切换**: 记录当前显示的图片索引

```javascript
onSwiperChange(e) {
  const current = e.detail.current || 0
  this.setData({
    currentImageIndex: current
  })
}
```

## 5. 关键特性

### 5.1 排序策略

**优先级**:
1. **主图优先**: `is_primary=True` 的图片最先显示
2. **顺序索引**: 按 `order_index` 升序排列
3. **稳定性**: 相同条件下按 `id` 排序，保证结果稳定

### 5.2 容错机制

1. **后端容错**: 
   - 如果没有图片，返回空数组
   - 如果图片URL为空，在序列化时会被包含但前端会过滤

2. **前端容错**:
   - 如果没有 `images` 数组，回退使用单图 `image_url`
   - 过滤无效URL（必须是http开头）
   - 前端去重，避免重复显示
   - 图片加载失败不影响其他图片显示

### 5.3 图片来源优先级

前端提取URL时的优先级：
1. `image_url` (COS存储URL，推荐)
2. `url` (备用字段)
3. `source_url` (原始来源URL)

## 6. 列表页 vs 详情页

### 6.1 列表页（首页）

**文件**: `miniprogram/pages/index/index.wxml`

列表页**只显示单张图片**（主图或第一张图片）：

```xml
<view class="property-item">
  <image 
    class="property-image" 
    src="{{item.image_url || '/image/default_property.png'}}" 
    mode="aspectFill" />
  <!-- 只显示一张图片 -->
</view>
```

**数据来源**: 
- 使用 `property.image_url`（房产表的主图字段）
- 如果没有 `image_url`，显示默认占位图

**特点**:
- 性能优化：列表页不需要加载所有图片
- 快速显示：只加载一张缩略图
- 点击跳转到详情页查看所有图片

### 6.2 详情页

**文件**: `miniprogram/pages/detail/detail.wxml`

详情页使用 **Swiper轮播**显示所有图片：

```xml
<swiper class="detail-swiper" indicator-dots="{{true}}">
  <block wx:for="{{property.imageUrls}}">
    <swiper-item>
      <image src="{{imgUrl}}" mode="aspectFill" />
    </swiper-item>
  </block>
</swiper>
```

**数据来源**:
- 使用 `property.images` 数组（从 `property_images` 表查询）
- 前端处理后生成 `imageUrls` 数组

**特点**:
- 完整展示：显示所有图片
- 轮播浏览：左右滑动查看
- 全屏预览：点击可全屏查看所有图片

## 9. 注意事项

1. **图片存储**: 推荐使用COS存储，`image_url` 应该是可公开访问的URL
2. **图片顺序**: 确保 `order_index` 正确设置，主图应设置 `is_primary=True`
3. **性能优化**: 大量图片时考虑分页或懒加载
4. **错误处理**: 前端会过滤无效URL，但后端也应确保URL格式正确
5. **缓存策略**: 可以考虑对图片URL进行缓存，减少重复处理
