## 配置说明

### 1. API地址配置
在 `app.js` 中修改 `globalData.apiBaseUrl`：
```javascript
globalData: {
  apiBaseUrl: 'http://localhost:5000'  // 修改为实际API地址
}
```

### 2. 本地开发
确保后端API服务正在运行：
```bash
cd backend
python simple_api.py
```

### 3. 微信开发者工具
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `miniprogram` 目录
4. 填写 AppID（可使用测试号）

## 使用说明

### 开发环境
1. 后端API运行在 `http://localhost:5000`
2. 使用微信开发者工具进行调试
3. 需要配置网络域名白名单

### 部署到生产环境
1. 修改 `app.js` 中的 API 地址为生产环境
2. 部署后端API到腾讯云
3. 配置域名和HTTPS
4. 上传小程序代码
