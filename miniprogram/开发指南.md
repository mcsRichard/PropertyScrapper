### 微信开发者工具配置网络请求

由于微信小程序对网络请求有限制，需要配置：

#### 方法1: 开发环境配置（推荐）

1. 打开微信开发者工具
2. 点击右上角 **"详情"**
3. 勾选 **"不校验合法域名、TLS 版本以及 HTTPS"**

✅ 这样可以在开发环境直接使用 `http://localhost:5000`

#### 方法2: 使用云服务器（生产环境）

如果需要发布小程序：
1. 将 `simple_api.py` 部署到腾讯云
2. 配置域名和 HTTPS
3. 在微信公众平台配置服务器域名白名单

### API地址配置

在小程序的 `app.js` 中，有一个重要的配置：

```javascript
globalData: {
  apiBaseUrl: 'http://localhost:5000'  // 这里配置API地址
}
```

**本地开发**：使用 `http://localhost:5000`  
**生产环境**：使用云服务器的实际地址，如 `https://api.yoursite.com`

### 完整启动流程

```bash
# 1. 启动后端服务（在项目根目录）
python simple_api.py

# 2. 在微信开发者工具中打开 miniprogram 目录
# 3. 配置网络请求（不校验合法域名）
# 4. 开始调试
```

### 验证连接

在小程序中打开控制台，应该能看到：
```
API连接成功: {status: "healthy"}
```

如果看到这个，说明小程序已经成功连接到后端API了！
