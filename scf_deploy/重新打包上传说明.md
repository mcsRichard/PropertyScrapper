# 重新打包上传说明

## ✅ 现在的文件结构

```
scf_deploy/
├── scf_bootstrap      ← 新创建的启动文件
├── index.py
├── requirements.txt
└── backend/
```

## 📦 打包步骤

### 1. 在 Windows 上设置文件权限（可选）

由于 Windows 不支持 Linux 权限，建议直接打包上传，腾讯云会自动处理。

### 2. 打包文件

**进入 scf_deploy 目录**，选中以下文件：
- `scf_bootstrap`
- `index.py`
- `requirements.txt`
- `backend/` 目录

右键 → "发送到" → "压缩(zipped)文件夹"

命名为：`property-api.zip`

### 3. 上传到腾讯云

1. 登录腾讯云控制台 → 云函数SCF
2. 如果之前的函数类型不对，删除重建：
   - **函数类型**：Web 函数
   - **运行环境**：Python 3.9
   - **创建方式**：从头开始
   - **代码上传**：先用示例代码创建

3. 函数创建后，进入"函数代码"
4. 选择"本地上传zip包"
5. 上传 `property-api.zip`
6. **点击"部署"按钮**
7. 等待1-2分钟（自动安装依赖）

### 4. 验证部署

部署完成后，在代码编辑器左侧应该看到：

```
/var/user/
├── scf_bootstrap     ✅ 必须有
├── index.py          ✅
├── requirements.txt  ✅
└── backend/          ✅
```

### 5. 测试

访问函数URL：
```
https://your-function-url/health
```

应该返回：
```json
{"status": "healthy", "message": "Property API is running"}
```

## 🔍 关键点

1. **scf_bootstrap 是必需的**（腾讯云官方文档要求）
2. **必须监听 9000 端口**
3. **requirements.txt 必须在根目录**才会自动安装依赖
4. **Python 3.9 使用 `/var/lang/python39/bin/python3.9`**

## 📝 如果还是报错

查看错误日志，常见问题：
- **405 错误**：scf_bootstrap 无法执行（权限或格式问题）
- **443 错误**：端口未监听或程序启动失败
- **ModuleNotFoundError**：requirements.txt 不在根目录或未部署
