# 云函数上传错误排查指南

## ❌ 错误信息

```
filename not matched: scf_bootstrap
BadCmqMsgError
```

## 🔍 原因分析

这个错误通常由以下原因导致：

1. **选择了"自定义运行环境"**（Custom Runtime）
   - 腾讯云期望找到 `scf_bootstrap` 文件
   - 但我们的项目是标准的 Python Web 函数，不需要这个文件

2. **上传的文件夹包含多余文件**
   - `__pycache__` 目录
   - `.env` 文件
   - 其他临时文件

3. **文件夹结构不正确**
   - 上传的层级不对
   - 缺少必要文件

---

## ✅ 解决方案

### 方案1：确认函数类型（最重要！）

#### 步骤1：检查当前函数类型

1. 在腾讯云控制台，打开你的函数详情页
2. 查看顶部或"函数配置"中显示的**运行环境**
3. 应该显示：**"Python 3.9 · Web 函数"** 或 **"Python 3.7 · Web 函数"**
4. **不应该显示**：**"自定义运行环境"** 或 **"Custom Runtime"**

#### 步骤2：如果显示"自定义运行环境"

**必须删除当前函数，重新创建！**

1. 删除当前函数（如果里面有重要配置，先截图保存）
2. 重新创建函数时：
   - **函数类型**：选择 **"Web 函数"**
   - **运行环境**：选择 **"Python 3.9"**（不要选"自定义运行环境"）
   - **创建方式**：选择 **"本地上传文件夹"**

---

### 方案2：清理部署包

#### 使用清理脚本（推荐）

在 `scf_deploy` 目录下运行：

```bash
清理部署包.bat
```

这个脚本会：
- 删除所有 `__pycache__` 目录
- 删除 `.env` 文件（敏感信息）
- 确保 `requirements.txt` 存在

#### 手动清理

确保 `scf_deploy` 目录结构如下：

```
scf_deploy/
├── index.py              ✅ 必须有
├── requirements.txt      ✅ 必须有
└── backend/              ✅ 必须有
    ├── app.py
    ├── config.py
    ├── api/
    ├── models/
    └── utils/
```

**删除以下内容**：
- ❌ `backend/__pycache__/`
- ❌ `backend/api/__pycache__/`
- ❌ `backend/models/__pycache__/`
- ❌ `backend/utils/__pycache__/`
- ❌ `backend/.env`
- ❌ 所有 `.md` 文档文件（可选，不影响但会增加上传大小）

---

### 方案3：使用ZIP上传（如果文件夹上传失败）

#### 步骤1：创建ZIP包

1. 在 `scf_deploy` 目录下
2. 选中以下文件/文件夹：
   - `index.py`
   - `requirements.txt`
   - `backend/` 目录
3. 右键 → "发送到" → "压缩(zipped)文件夹"
4. 命名为：`property-api.zip`

#### 步骤2：上传ZIP

1. 在云函数代码编辑器中
2. 选择 **"本地上传ZIP包"**
3. 选择刚才创建的 `property-api.zip`
4. 上传

---

### 方案4：在线编辑（如果上传一直失败）

#### 步骤1：先创建函数

1. 创建函数时选择 **"空白函数"**
2. 运行环境：**Python 3.9 Web 函数**

#### 步骤2：在线创建文件

在云函数代码编辑器中，逐个创建文件：

1. **创建 `index.py`**：
   - 点击"新建文件"
   - 文件名：`index.py`
   - 复制 `scf_deploy/index.py` 的内容

2. **创建 `requirements.txt`**：
   - 点击"新建文件"
   - 文件名：`requirements.txt`
   - 复制 `scf_deploy/requirements.txt` 的内容

3. **创建 `backend` 目录**：
   - 点击"新建文件夹"
   - 文件夹名：`backend`
   - 在 `backend` 下逐个创建文件

**注意**：这种方式比较繁琐，建议优先使用方案1-3。

## 🔧 配置检查清单

上传成功后，确认以下配置：

### 函数配置
- [ ] **运行环境**：Python 3.9 或 Python 3.7（不是自定义运行环境）
- [ ] **函数类型**：Web 函数
- [ ] **入口文件**：`index.py`
- [ ] **入口函数**：`app`（不是 `main_handler`）

### 高级配置
- [ ] **启动命令**：`python index.py`
- [ ] **执行超时**：60秒（或更长）
- [ ] **内存配置**：512MB（或更高）

### 代码结构
- [ ] `index.py` 在根目录
- [ ] `requirements.txt` 在根目录
- [ ] `backend/` 目录在根目录
- [ ] 没有 `__pycache__` 目录
- [ ] 没有 `.env` 文件

---

## 🆘 如果还是失败

### 1. 检查腾讯云控制台提示

上传失败时，腾讯云会显示具体错误信息，请截图或复制完整错误信息。

### 2. 检查文件大小

- 云函数对代码包大小有限制（通常50MB）
- 如果 `backend` 目录太大，可能需要：
  - 删除 `scripts/` 目录（这些是本地脚本，不需要上传）
  - 删除文档文件

### 3. 联系腾讯云支持

如果以上方法都不行，可以：
- 在腾讯云控制台提交工单
- 提供错误信息和函数配置截图

---

## 📝 正确的上传流程总结

1. ✅ **选择函数类型**：Web 函数（Python 3.9）
2. ✅ **清理部署包**：运行 `清理部署包.bat`
3. ✅ **上传方式**：本地上传文件夹（选择 `scf_deploy` 目录）
4. ✅ **配置入口**：`index.py`，函数：`app`
5. ✅ **配置启动命令**：`python index.py`
6. ✅ **测试**：访问 `/health` 接口
