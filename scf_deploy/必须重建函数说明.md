# ⚠️ 必须重建函数 - 错误原因和解决方案

## 🔴 错误原因

你看到的错误：
```
filename not matched: scf_bootstrap
```

**这个错误100%确定：你创建的函数类型是"自定义运行环境"，而不是"Python Web函数"。**

腾讯云在解压你的代码时，期望找到 `scf_bootstrap` 文件（这是自定义运行环境需要的），但你的项目是标准Python Web函数，不需要这个文件。

---

## ✅ 解决方案：删除并重建函数

### 步骤1：删除当前函数

1. 在腾讯云控制台
2. 进入云函数SCF服务
3. 找到你的函数（比如 `property-api`）
4. 点击函数名称进入详情页
5. 点击右上角 **"删除"** 或 **"更多" → "删除"**
6. 确认删除

**⚠️ 注意**：如果函数里有重要配置（环境变量等），先截图保存！

---

### 步骤2：重新创建函数（关键步骤）

#### 2.1 点击"新建函数"

#### 2.2 选择函数类型（最重要！）

在创建页面，你会看到类似这样的选项：

```
○ 从头开始
○ 使用模板
○ 使用容器镜像
```

选择：**"从头开始"**

#### 2.3 配置函数基本信息

**关键配置**：

1. **函数类型**：
   - 选择：**"Web函数"** ✅
   - **不要选**："事件函数" ❌

2. **运行环境**：
   - 选择：**"Python 3.9"** ✅
   - 或：**"Python 3.7"** ✅
   - **绝对不要选**："自定义运行环境" ❌
   - **绝对不要选**："Custom Runtime" ❌

3. **函数名称**：
   - 填写：`property-api`（或你喜欢的名称）

4. **地域**：
   - 选择：**华东地区（上海）**（与数据库、COS保持一致）

#### 2.4 配置代码（关键！）

在"代码"部分：

1. **创建方式**：
   - 选择：**"本地上传文件夹"** ✅
   - 或：**"本地上传ZIP包"** ✅

2. **选择文件**：
   - 如果选择"本地上传文件夹"：
     - 选择 `scf_deploy` 目录（不是里面的文件）
   - 如果选择"本地上传ZIP包"：
     - 先压缩 `scf_deploy` 目录为ZIP
     - 选择ZIP文件

3. **入口配置**：
   - **入口文件**：`index.py`
   - **入口函数**：`app`（不是 `main_handler`）

#### 2.5 高级配置

1. **启动命令**：
   - 填写：`python index.py`

2. **执行超时**：
   - 设置为：60秒（或更长）

3. **内存配置**：
   - 设置为：512MB（或更高）

#### 2.6 完成创建

点击"完成"或"创建"，等待函数创建完成。

---

### 步骤3：验证函数类型

创建成功后，在函数详情页顶部，应该显示：

```
运行环境：Python 3.9 · Web 函数
```

**不应该显示**：
- ❌ "自定义运行环境"
- ❌ "Custom Runtime"

---

### 步骤4：重新配置环境变量

如果之前有环境变量配置，需要重新添加：

1. 进入函数详情页
2. 点击"函数配置" → "环境变量"
3. 按照 `环境变量配置清单.md` 添加所有环境变量

---

## 🎯 快速检查清单

创建函数时，确认以下所有项：

- [ ] 选择了"Web函数"（不是事件函数）
- [ ] 运行环境选择了"Python 3.9"或"Python 3.7"（不是自定义运行环境）
- [ ] 上传了 `scf_deploy` 目录
- [ ] 入口文件配置为：`index.py`
- [ ] 入口函数配置为：`app`
- [ ] 启动命令配置为：`python index.py`
- [ ] 创建成功后，运行环境显示"Python 3.9 · Web 函数"

---

## 🆘 如果创建时没有"Web函数"选项

如果创建页面没有"Web函数"选项，可能是：

1. **控制台版本问题**：
   - 尝试刷新页面
   - 或使用最新版浏览器

2. **地域问题**：
   - 确保选择的地域支持Web函数
   - 建议选择：华东地区（上海）

3. **账号权限问题**：
   - 确认账号有创建Web函数的权限

## 💡 为什么会出现这个错误？

腾讯云有两种函数类型：

1. **标准Web函数**（我们要用的）：
   - 选择Python 3.9运行环境
   - 直接运行Python代码
   - 不需要 `scf_bootstrap`

2. **自定义运行环境**（不要选）：
   - 需要自己提供运行环境
   - 需要 `scf_bootstrap` 启动脚本
   - 更复杂，不适合我们的项目

**你之前可能误选了"自定义运行环境"，所以才会报这个错误。**

---

## ✅ 总结

**必须做的**：
1. 删除当前函数
2. 重新创建函数
3. 确保选择"Python 3.9 Web函数"（不是自定义运行环境）
4. 重新上传代码
5. 重新配置环境变量

**不要做的**：
- ❌ 不要尝试修复当前函数（类型不对，无法修复）
- ❌ 不要选择"自定义运行环境"
- ❌ 不要选择"事件函数"

按照以上步骤重建函数后，就不会再出现 `scf_bootstrap` 错误了！
