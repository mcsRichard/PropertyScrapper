# 快速部署指南 - 5步完成

## 🎯 目标
将后端API部署到腾讯云SCF，配置环境变量和HTTP触发器。

---

## 📋 准备工作

### 1. 准备部署包
运行准备脚本：
```bash
# 在 scf_deploy 目录下
准备部署包.bat
```

或手动操作：
1. 将 `backend` 目录复制到 `scf_deploy` 目录下
2. 确认 `scf_deploy` 目录包含：
   - `index.py`
   - `requirements.txt`
   - `backend/` 目录

---

## 🚀 部署步骤

### 步骤1：创建云函数（5分钟）

1. **登录腾讯云控制台**
   - 访问：https://console.cloud.tencent.com/
   - 登录账号

2. **进入云函数服务**
   - 搜索"云函数"或"SCF"
   - 点击进入

3. **创建新函数**
   - 点击"新建函数"
   - **选择"Web函数"**（重要！）
   - 地域选择：**华东地区（上海）**
   - 函数名称：`property-api`
   - 运行环境：`Python 3.9`（推荐）或 `Python 3.7`

4. **上传代码**
   - 创建方式：选择"本地上传文件夹"
   - 选择 `scf_deploy` 目录
   - 上传

5. **配置入口**
   - 入口文件：`index.py`
   - 入口函数：`app`（注意：不是 `main_handler`）

---

### 步骤2：配置环境变量（10分钟）

1. **进入环境变量配置**
   - 在函数详情页
   - 点击"函数配置"标签
   - 找到"环境变量"
   - 点击"编辑"

2. **添加环境变量**
   
   参考 `环境变量配置清单.md`，添加以下变量：

   **数据库配置**（必填）：
   ```
   DB_HOST=sh-cynosdbmysql-grp-jfymqerg.sql.tencentcdb.com
   DB_PORT=29493
   DB_USER=your-root
   DB_PASSWORD=Yxn791121!
   DB_NAME=ukestate
   ```

   **COS配置**（必填）：
   ```
   COS_SECRET_ID=your-cos-secret-id
   COS_SECRET_KEY=your-cos-secret-key
   COS_REGION=ap-shanghai
   COS_BUCKET=your-bucket-name
   ```

   **AI配置**（如使用AI搜索）：
   ```
   AI_API_TYPE=deepseek
   DEEPSEEK_API_KEY=your-deepseek-api-key
   ```

   **其他配置**：
   ```
   DEBUG=False
   ```

3. **保存配置**
   - 点击"保存"
   - 等待配置生效

---

### 步骤3：配置HTTP触发器（5分钟）

1. **创建触发器**
   - 在函数详情页
   - 点击"触发器管理"标签
   - 点击"创建触发器"

2. **配置触发器**
   - **触发方式**：API网关触发器
   - **API网关类型**：新建API网关服务
   - **请求方法**：ANY
   - **发布环境**：发布
   - **路径配置**：`/api/{proxy+}`
   - **启用CORS**：✅ 勾选（重要！）

3. **保存触发器**
   - 点击"完成"
   - 记录生成的API网关地址

---

### 步骤4：测试部署（5分钟）

1. **测试健康检查**
   ```
   https://your-api-gateway-url/health
   ```
   应该返回：
   ```json
   {
     "status": "healthy",
     "message": "Property API is running"
   }
   ```

2. **测试API接口**
   ```
   https://your-api-gateway-url/api/properties?page=1&limit=10
   ```
   应该返回房产列表数据

3. **查看日志**
   - 在函数详情页
   - 点击"日志查询"
   - 检查是否有错误

---

### 步骤5：优化配置（可选，5分钟）

1. **调整函数配置**
   - 执行超时时间：60秒（或更长）
   - 内存配置：512MB（或更高）

2. **验证配置**
   - 再次测试API接口
   - 确认响应正常

## 🆘 遇到问题？

### 问题1：函数执行失败
- 查看日志确认错误信息
- 检查环境变量配置
- 验证代码文件完整性

### 问题2：API返回502
- 检查函数是否正常运行
- 查看日志中的错误信息
- 验证数据库连接

### 问题3：CORS跨域错误
- 确保HTTP触发器已启用CORS
- 检查Flask应用中的CORS配置

### 问题4：模块导入失败
- 检查 `requirements.txt` 是否已上传
- 查看日志确认具体错误

**更多问题排查**：查看 `部署步骤详细说明.md` 中的"常见问题排查"章节
