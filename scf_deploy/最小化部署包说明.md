# 最小化部署包说明

## 🎯 问题

如果上传完整 `backend` 目录失败（可能因为文件太大或包含不需要的文件），可以使用最小化部署包。

---

## 📦 最小化部署包结构

只需要以下文件：

```
scf_deploy/
├── index.py
├── requirements.txt
└── backend/
    ├── __init__.py
    ├── app.py
    ├── config.py
    ├── api/
    │   ├── __init__.py
    │   ├── admin.py
    │   └── properties.py
    ├── models/
    │   ├── __init__.py
    │   └── database.py
    └── utils/
        ├── __init__.py
        ├── ai_parser.py
        ├── cos_uploader.py
        └── location_mapper.py
```

**不需要的文件**：
- ❌ `backend/scripts/` - 本地脚本，不需要
- ❌ `backend/README.md` - 文档文件
- ❌ `backend/env_example.txt` - 示例文件
- ❌ 所有 `__pycache__/` 目录
- ❌ `.env` 文件

---

## 🚀 创建最小化部署包

### 方法1：使用PowerShell脚本

在项目根目录运行：

```powershell
# 创建最小化部署目录
$minimalDir = "scf_deploy_minimal"
New-Item -ItemType Directory -Path $minimalDir -Force
New-Item -ItemType Directory -Path "$minimalDir\backend" -Force
New-Item -ItemType Directory -Path "$minimalDir\backend\api" -Force
New-Item -ItemType Directory -Path "$minimalDir\backend\models" -Force
New-Item -ItemType Directory -Path "$minimalDir\backend\utils" -Force

# 复制必要文件
Copy-Item "scf_deploy\index.py" "$minimalDir\"
Copy-Item "scf_deploy\requirements.txt" "$minimalDir\"
Copy-Item "backend\__init__.py" "$minimalDir\backend\"
Copy-Item "backend\app.py" "$minimalDir\backend\"
Copy-Item "backend\config.py" "$minimalDir\backend\"
Copy-Item "backend\api\*" "$minimalDir\backend\api\" -Recurse -Exclude "__pycache__"
Copy-Item "backend\models\*" "$minimalDir\backend\models\" -Recurse -Exclude "__pycache__"
Copy-Item "backend\utils\*" "$minimalDir\backend\utils\" -Recurse -Exclude "__pycache__"

Write-Host "最小化部署包已创建：$minimalDir"
```

### 方法2：手动复制

1. 创建新目录：`scf_deploy_minimal`
2. 复制以下文件：
   - `scf_deploy/index.py` → `scf_deploy_minimal/index.py`
   - `scf_deploy/requirements.txt` → `scf_deploy_minimal/requirements.txt`
3. 创建 `scf_deploy_minimal/backend/` 目录
4. 从 `backend/` 复制以下内容：
   - `__init__.py`
   - `app.py`
   - `config.py`
   - `api/` 目录（整个目录，但排除 `__pycache__`）
   - `models/` 目录（整个目录，但排除 `__pycache__`）
   - `utils/` 目录（整个目录，但排除 `__pycache__`）

---

## ✅ 上传最小化部署包

1. 在腾讯云控制台
2. 选择"本地上传文件夹"
3. 选择 `scf_deploy_minimal` 目录
4. 上传

---

## 📝 注意事项

- 最小化部署包只包含运行API必需的文件
- 如果需要运行爬虫脚本，需要额外上传 `scripts/` 目录
- 环境变量配置仍然需要在云函数控制台设置
