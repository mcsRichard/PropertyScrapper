# 腾讯云SCF部署详细步骤

## 📋 部署前准备

### 1. 确认所需资源
- ✅ 腾讯云账号
- ✅ TDSQL-C数据库（已配置）
- ✅ COS存储桶（已创建）
- ✅ 域名（已备案）

### 2. 准备部署文件
确保以下文件已准备好：
- `index.py` - 云函数入口文件（已创建）
- `backend/` - 完整的backend目录
- `requirements.txt` - Python依赖文件

---

## 🚀 第一步：创建云函数

### 1.1 登录腾讯云控制台
1. 访问：https://console.cloud.tencent.com/
2. 登录您的腾讯云账号

### 1.2 进入云函数服务
1. 在控制台搜索"云函数"或"SCF"
2. 点击进入"云函数SCF"服务

### 1.3 创建新函数
1. 点击"新建函数"按钮
2. 选择"Web函数"（重要：必须是Web函数，不是事件函数）
3. 选择地域：**华东地区（上海）**（与数据库和COS保持一致）

### 1.4 配置函数基本信息
- **函数名称**：`property-api`（或您喜欢的名称）
- **运行环境**：`Python 3.7` 或 `Python 3.9`（推荐3.9）
- **创建方式**：选择"本地上传文件夹"或"在线编辑"（建议先在线编辑入口文件）

---

## 📦 第二步：上传代码

### 方式1：在线编辑（先创建函数）

#### 2.1 创建入口文件
1. 在云函数代码编辑器中
2. 创建文件 `index.py`
3. 复制以下代码：

```python
# -*- coding: utf-8 -*-
import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'backend'))
from app import create_app
app = create_app()
```

4. 点击"保存"

#### 2.2 配置入口设置
- **入口文件**：`index.py`
- **入口函数**：`app`（注意：不是 `main_handler`，而是 `app`）

#### 2.3 上传backend目录
1. 在云函数代码编辑器中
2. 点击"上传文件"或"本地上传文件夹"
3. 选择整个 `backend` 目录上传
4. 等待上传完成

### 方式2：本地上传完整包（推荐）

#### 2.1 准备部署包
在本地创建以下目录结构：
```
scf_deploy/
├── index.py              # 云函数入口文件
├── backend/               # 整个backend目录
│   ├── app.py
│   ├── config.py
│   ├── requirements.txt
│   ├── api/
│   ├── models/
│   └── utils/
└── requirements.txt       # 依赖文件（从backend复制）
```

#### 2.2 压缩部署包
1. 将 `scf_deploy` 目录压缩为 `.zip` 文件
2. 确保压缩包内结构正确

#### 2.3 上传到云函数
1. 在云函数代码编辑器中
2. 点击"本地上传文件夹"或"上传ZIP包"
3. 选择压缩包上传
4. 等待上传完成

## 🔗 第四步：配置HTTP触发器

### 4.1 创建触发器
1. 在云函数详情页
2. 点击"触发器管理"标签
3. 点击"创建触发器"

### 4.2 配置触发器
- **触发方式**：选择"API网关触发器"
- **API网关类型**：选择"新建API网关服务"或使用现有服务
- **请求方法**：选择"ANY"（支持所有HTTP方法）
- **发布环境**：选择"发布"（生产环境）
- **路径配置**：`/api/{proxy+}`（这样所有 `/api/*` 的请求都会转发到函数）
- **启用CORS**：✅ 勾选（重要：小程序需要跨域支持）

### 4.3 保存触发器
1. 点击"完成"
2. 等待触发器创建完成
3. 记录生成的API网关地址（格式：`https://xxx.apigw.tencentcs.com`）

## ✅ 第五步：测试部署

### 5.1 测试健康检查接口
1. 在浏览器中访问：
   ```
   https://your-api-gateway-url/health
   ```
2. 应该返回：
   ```json
   {
     "status": "healthy",
     "message": "Property API is running"
   }
   ```

### 5.2 测试API接口
1. 测试列表接口：
   ```
   https://your-api-gateway-url/api/properties?page=1&limit=10
   ```
2. 应该返回房产列表数据

### 5.3 查看日志
1. 在云函数详情页
2. 点击"日志查询"标签
3. 查看是否有错误日志
4. 如有错误，根据日志信息排查问题

## 🔧 常见问题排查

### 问题1：函数执行超时
**解决方案**：
1. 在"函数配置"中
2. 增加"执行超时时间"（建议设置为60秒）

### 问题2：内存不足
**解决方案**：
1. 在"函数配置"中
2. 增加"内存配置"（建议设置为512MB或更高）

### 问题3：导入模块失败
**解决方案**：
1. 检查 `requirements.txt` 是否已上传
2. 检查依赖是否完整
3. 查看日志确认具体错误

### 问题4：数据库连接失败
**解决方案**：
1. 检查环境变量中的数据库配置是否正确
2. 检查数据库白名单是否包含云函数IP
3. 测试数据库连接是否正常

### 问题5：CORS跨域错误
**解决方案**：
1. 确保HTTP触发器已启用CORS
2. 检查Flask应用中的CORS配置
