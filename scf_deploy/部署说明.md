# 云函数部署说明

## 📦 部署包结构

```
scf_deploy/
├── index.py              # 云函数入口文件（必须）
├── backend/              # 整个backend目录（需要复制）
│   ├── app.py
│   ├── config.py
│   ├── requirements.txt
│   ├── api/
│   ├── models/
│   └── utils/
└── requirements.txt      # 依赖文件（从backend复制）
```

## 📋 部署步骤

### 步骤1: 准备部署包

1. **复制backend目录到scf_deploy**
   ```bash
   # 在项目根目录执行
   xcopy /E /I backend scf_deploy\backend
   ```

2. **复制requirements.txt**
   ```bash
   copy backend\requirements.txt scf_deploy\requirements.txt
   ```

3. **确认index.py已存在**
   - 已在 `scf_deploy/index.py`

### 步骤2: 上传到云函数

#### 方式1: 本地上传文件夹（推荐）

1. 登录腾讯云控制台
2. 进入云函数SCF服务
3. 找到你的函数（如：property-api）
4. 点击"函数代码"
5. 选择"本地上传文件夹"
6. 选择 `scf_deploy` 目录
7. 点击"上传"

#### 方式2: 在线编辑（不推荐，代码太多）

1. 在云函数代码编辑器中
2. 逐个创建文件和目录
3. 粘贴代码内容

### 步骤3: 配置入口

1. **入口文件**：`index.py`
2. **入口函数**：`app`
3. **函数类型**：Web函数（已选择）

### 步骤4: 配置环境变量

见 `环境变量配置.md`

### 步骤5: 配置HTTP触发器

见 `HTTP触发器配置.md`

---

## ⚠️ 注意事项

1. **不要上传.env文件**
   - 环境变量在云函数控制台配置
   - 不要包含敏感信息

2. **不要上传__pycache__**
   - 这些是Python缓存文件
   - 云函数会自动处理

3. **requirements.txt位置**
   - 必须在根目录（与index.py同级）
   - 云函数会自动安装依赖

4. **Python版本**
   - 确保云函数运行环境与本地一致
   - 推荐：Python 3.7 或 3.8

## 🆘 常见问题

### Q1: 上传后报错"找不到模块"？
**解决**：
- 检查backend目录是否完整上传
- 检查requirements.txt是否在根目录
- 查看云函数日志定位具体错误

### Q2: 环境变量不生效？
**解决**：
- 确认在云函数"环境变量"配置中设置
- 确认变量名与config.py中一致
- 重启云函数

### Q3: HTTP触发器无法访问？
**解决**：
- 确认已配置HTTP触发器
- 确认域名已绑定
- 确认SSL证书已配置
