## 🚀 部署步骤

### 步骤1: 准备部署包（5分钟）

#### 1.1 复制backend目录

在项目根目录执行：

**Windows (PowerShell)**:
```powershell
# 创建backend目录
New-Item -ItemType Directory -Force -Path scf_deploy\backend

# 复制所有文件（排除__pycache__）
Copy-Item -Path backend\* -Destination scf_deploy\backend -Recurse -Exclude __pycache__

# 删除__pycache__目录（如果已复制）
Get-ChildItem -Path scf_deploy\backend -Recurse -Filter __pycache__ | Remove-Item -Recurse -Force
```

**Windows (CMD)**:
```cmd
xcopy /E /I /EXCLUDE:exclude.txt backend scf_deploy\backend
```

创建 `exclude.txt` 文件：
```
__pycache__
*.pyc
.env
```

#### 1.2 复制requirements.txt

```cmd
copy backend\requirements.txt scf_deploy\requirements.txt
```

#### 1.3 验证文件结构

确认 `scf_deploy` 目录包含：
- ✅ `index.py`
- ✅ `backend/` 目录（包含所有文件）
- ✅ `requirements.txt`

---

### 步骤2: 创建或选择云函数（10分钟）

#### 2.1 登录腾讯云控制台

访问：https://console.cloud.tencent.com/scf

#### 2.2 创建新函数（如果还没有）

1. 点击"新建函数"
2. 选择"从头开始"
3. 配置基本信息：
   - **函数名称**：`property-api`
   - **地域**：`华东地区（上海）` - ap-shanghai
   - **运行环境**：`Python 3.7` 或 `Python 3.8`
   - **函数类型**：`Web函数` ⚠️ 重要！
4. 点击"下一步"
5. 配置高级设置：
   - **执行超时**：`60秒`
   - **内存**：`128MB`（免费额度）
6. 点击"完成"

#### 2.3 或选择已有函数

如果已经创建过函数，直接选择即可。

---

### 步骤3: 上传代码（10分钟）

#### 3.1 进入函数代码

1. 点击函数名称进入详情
2. 点击"函数代码"标签

#### 3.2 上传部署包

**方式1: 本地上传文件夹（推荐）**

1. 点击"本地上传文件夹"
2. 选择 `scf_deploy` 目录
3. 点击"上传"
4. 等待上传完成（可能需要几分钟）

**方式2: 在线编辑（不推荐）**

如果代码较少，可以在线编辑，但代码多时不推荐。

#### 3.3 配置入口

1. **入口文件**：`index.py`
2. **入口函数**：`app`
3. **函数类型**：确认是 `Web函数`

#### 3.4 保存并部署

1. 点击"保存"
2. 等待部署完成
3. 查看部署日志，确认无错误

---

### 步骤4: 配置环境变量（10分钟）

#### 4.1 进入环境变量配置

1. 点击"函数配置"标签
2. 找到"环境变量"部分
3. 点击"编辑"

#### 4.2 添加环境变量

参考 `环境变量配置.md`，逐个添加：

**数据库配置**：
- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`

**COS配置**：
- `COS_SECRET_ID`
- `COS_SECRET_KEY`
- `COS_REGION`
- `COS_BUCKET`
- `COS_DOMAIN`（可选）

**AI配置**：
- `AI_API_TYPE`
- `DEEPSEEK_API_KEY`
- `DEEPSEEK_API_BASE`（可选）
- `DEEPSEEK_MODEL`（可选）

**其他配置**：
- `DEBUG=False`（生产环境）

#### 4.3 保存配置

1. 点击"保存"
2. 等待配置生效

---

### 步骤5: 配置HTTP触发器（15分钟）

#### 5.1 进入触发器管理

1. 点击"触发器管理"标签
2. 点击"创建触发器"

#### 5.2 配置触发器

- **触发方式**：`API Gateway触发器`
- **API网关**：选择"新建API网关服务"或使用已有服务
- **请求方法**：`ANY`
- **发布环境**：`发布`
- **路径配置**：`/{proxy+}` ⚠️ 推荐
- **启用CORS**：✅ 勾选

#### 5.3 保存配置

1. 点击"完成"
2. 等待触发器创建完成
3. 记录临时域名（格式：`https://service-xxx-xxx.apigw.tencentcs.com`）

---

### 步骤6: 绑定域名和SSL（20分钟）

#### 6.1 申请SSL证书

1. 进入SSL证书服务：https://console.cloud.tencent.com/ssl
2. 点击"申请免费证书"
3. 选择"单域名"
4. 输入域名（如：`api.yoursite.com`）
5. 完成域名验证
6. 等待证书签发（0.5-2小时）

#### 6.2 配置DNS解析

1. 在域名服务商处配置DNS
2. 添加CNAME记录：
   - 主机记录：`api`
   - 记录值：API网关提供的CNAME地址
3. 等待DNS生效

#### 6.3 绑定域名到API网关

1. 进入API网关控制台：https://console.cloud.tencent.com/apigateway
2. 找到你的API网关服务
3. 点击"自定义域名"
4. 点击"新建"
5. 输入域名
6. 选择协议：`HTTPS`
7. 选择SSL证书
8. 配置路径映射
9. 保存

---

### 步骤7: 验证部署（10分钟）

#### 7.1 测试健康检查

使用临时域名或自定义域名：

```bash
curl https://your-domain.com/health
```

**预期返回**：
```json
{
  "status": "healthy",
  "message": "Property API is running"
}
```

#### 7.2 测试API接口

```bash
curl https://your-domain.com/api/properties?page=1&limit=10
```

**预期返回**：房产列表JSON数据

#### 7.3 检查云函数日志

1. 进入云函数控制台
2. 点击"日志查询"
3. 查看是否有错误日志

## 🆘 常见问题排查

### 问题1: 上传后报错"找不到模块"

**原因**：
- backend目录未完整上传
- requirements.txt位置不对

**解决**：
1. 检查backend目录是否完整
2. 确认requirements.txt在根目录
3. 查看云函数日志定位具体错误

### 问题2: 环境变量不生效

**原因**：
- 变量名拼写错误
- 未保存配置

**解决**：
1. 检查变量名与config.py中一致（大小写敏感）
2. 确认已保存配置
3. 重新部署云函数

### 问题3: HTTP触发器无法访问

**原因**：
- 路径配置错误
- CORS未启用

**解决**：
1. 检查路径配置（推荐使用/{proxy+}）
2. 确认CORS已启用
3. 检查API网关服务状态

### 问题4: 数据库连接失败

**原因**：
- 环境变量配置错误
- 数据库白名单未配置

**解决**：
1. 检查数据库环境变量
2. 在数据库控制台添加云函数IP到白名单
3. 测试数据库连接
