# 云函数环境变量配置清单

## 📋 必需环境变量

在腾讯云云函数控制台中，进入"函数配置" > "环境变量"，添加以下变量：

### 1. 数据库配置（TDSQL-C Serverless）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `DB_HOST` | 数据库地址 | `sh-cynosdbmysql-grp-jfymqerg.sql.tencentcdb.com` |
| `DB_PORT` | 数据库端口 | `29493` |
| `DB_USER` | 数据库用户名 | `your-root` |
| `DB_PASSWORD` | 数据库密码 | `SunnyDay!47_Rose` |
| `DB_NAME` | 数据库名称 | `ukestate` |

### 2. 腾讯云COS配置（图片存储）

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `COS_SECRET_ID` | COS密钥ID | `AKIDxxxxxxxxxxxxx` |
| `COS_SECRET_KEY` | COS密钥 | `xxxxxxxxxxxxxxxxxxxxx` |
| `COS_REGION` | COS地域 | `ap-shanghai` |
| `COS_BUCKET` | COS存储桶名称 | `your-bucket-name` |
| `COS_DOMAIN` | COS自定义域名（可选） | `https://your-cdn-domain.com` |

### 3. AI搜索功能配置

| 变量名 | 说明 | 示例值 | 必填 |
|--------|------|--------|------|
| `AI_API_TYPE` | AI API类型 | `deepseek` 或 `openai` | 否（默认deepseek） |
| `DEEPSEEK_API_KEY` | DeepSeek API密钥 | `sk-xxxxxxxxxxxxx` | 是（如果使用DeepSeek） |
| `DEEPSEEK_API_BASE` | DeepSeek API地址 | `https://api.deepseek.com` | 否（默认值） |
| `DEEPSEEK_MODEL` | DeepSeek模型 | `deepseek-chat` | 否（默认值） |
| `OPENAI_API_KEY` | OpenAI API密钥 | `sk-xxxxxxxxxxxxx` | 否（如果使用OpenAI） |
| `OPENAI_API_BASE` | OpenAI API地址 | `https://api.openai.com/v1` | 否（默认值） |
| `OPENAI_MODEL` | OpenAI模型 | `gpt-4o-mini` | 否（默认值） |

### 4. API配置（可选）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `API_HOST` | API主机 | `0.0.0.0` |
| `API_PORT` | API端口 | `5000` |
| `DEBUG` | 调试模式 | `False`（生产环境建议False） |

## 🔧 配置步骤

### 在腾讯云控制台配置

1. **登录腾讯云控制台**
   - 访问：https://console.cloud.tencent.com/scf

2. **进入云函数**
   - 找到你的函数（如：property-api）
   - 点击函数名称进入详情

3. **进入环境变量配置**
   - 点击"函数配置"标签
   - 找到"环境变量"部分
   - 点击"编辑"

4. **添加环境变量**
   - 点击"新增变量"
   - 输入变量名和变量值
   - 逐个添加所有必需变量

5. **保存配置**
   - 点击"保存"
   - 等待配置生效（通常几秒钟）

## ⚠️ 安全注意事项

1. **不要提交.env文件到代码仓库**
   - 环境变量包含敏感信息
   - 使用云函数环境变量配置

2. **定期轮换密钥**
   - 建议每3-6个月更换一次密钥
   - 更换后立即更新环境变量

3. **使用最小权限原则**
   - COS密钥只授予必要的权限
   - 数据库用户只授予必要的权限

4. **生产环境关闭DEBUG**
   - 设置 `DEBUG=False`
   - 避免泄露敏感信息

## ✅ 验证配置

配置完成后，可以通过以下方式验证：

1. **查看云函数日志**
   - 如果配置错误，日志中会显示错误信息

2. **测试API接口**
   - 访问健康检查接口
   - 如果返回正常，说明配置正确

3. **检查数据库连接**
   - 测试API接口返回数据
   - 如果能正常返回数据，说明数据库配置正确

## 🆘 常见问题

### Q1: 环境变量不生效？
**解决**：
- 确认变量名与config.py中一致（大小写敏感）
- 确认已保存配置
- 重启云函数（重新部署）

### Q2: 数据库连接失败？
**检查**：
- DB_HOST是否正确
- DB_PORT是否正确
- DB_USER和DB_PASSWORD是否正确
- 数据库白名单是否包含云函数IP

### Q3: COS上传失败？
**检查**：
- COS_SECRET_ID和COS_SECRET_KEY是否正确
- COS_REGION是否与存储桶地域一致
- COS_BUCKET名称是否正确

### Q4: AI搜索功能不工作？
**检查**：
- DEEPSEEK_API_KEY或OPENAI_API_KEY是否正确
- API密钥是否有效
- 账户余额是否充足
